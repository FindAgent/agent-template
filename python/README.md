# Python code agent (Python 3.13)

A complete FindAgent code agent: a crates.io health check served as an MCP server over stdio, with the
six entry tools, a result panel, and every platform rule met. Read the [root README](../README.md) for the
Agent Plugins model, the checklist and the pitfalls. This file is the Python specifics.

The sandbox runs `pip install -r requirements.txt --target <deps>` and then `python3 server.py`. That is
all it does, so everything the agent needs must be in `requirements.txt` as exact pins with a binary wheel,
and the panel must already be built and committed (there is no build step).

## Layout

| Path | What |
|---|---|
| `server.py` | entrypoint (`findagent.json` `entrypoint`) |
| `agent_template/mcp_server.py` | the stdio server: tools, the panel resource, elicitation, logging to stderr |
| `agent_template/tools.py` | the seven tools, the `needs_input` shapes, the panel binding |
| `agent_template/check.py`, `signals.py`, `crates.py`, `http.py` | the check itself (the part you replace) |
| `panel/` | panel source built into `ui/index.html` by `scripts/build_panel.py` (committed) |
| `findagent.json` | the contract; `skills[]` is generated by `scripts/sync_manifest.py` |
| `requirements.txt` | what the sandbox installs; `requirements-dev.txt` adds the dev tools |
| `tests/` | unit, contract, stdio (real MCP client), panel (real Chromium), platform-check tests |

## Commands

```
python -m venv .venv && . .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python -m playwright install chromium            # for the panel tests
ruff check . && ruff format --check .
mypy agent_template server.py scripts
pytest
python scripts/sync_manifest.py --check && python scripts/build_panel.py --check
python scripts/check_platform.py                 # add --wheels to ask PyPI for a Linux wheel per pin
python scripts/live_check.py                     # the server over stdio against the real crates.io
```

## Making it yours

1. Replace `crates.py`, `signals.py` and `check.py` with your logic; keep `http.py` as the only code that
   touches the network, and keep redirects off.
2. Update `TOOLS` in `agent_template/tools.py`, then run `python scripts/sync_manifest.py`.
3. Change `allowed_hosts` in `findagent.json` to exactly the hosts you call (an agent that calls nothing
   has an empty list).
4. Edit `panel/` and run `python scripts/build_panel.py`; commit the rebuilt `ui/index.html`.
5. Add dependencies to `requirements.txt` as `name==x.y.z`, then `python scripts/check_platform.py --wheels`.
6. Never `print()`: stdout is the MCP stream. Log with `sys.stderr` or `logging`.
